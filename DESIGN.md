# Design

## Visual Theme

Cotton parcel with a red wax seal. Off-white shop paper, red as stamp and rule — not as a streetwear accent on a white mega-catalog. No carousel, no pill filters, no centered ghost-logo header.

## Colors

| Role | OKLCH | Use |
| --- | --- | --- |
| bg | `oklch(0.97 0.012 25)` | Off-white paper |
| surface | `oklch(0.99 0.006 25)` | Header, tables |
| ink | `oklch(0.24 0.04 25)` | Body |
| primary | `oklch(0.50 0.19 27)` | Seal, rules, links |
| accent | `oklch(0.28 0.06 25)` | Dark red-brown ink |
| muted | `oklch(0.45 0.03 25)` | Captions |
| on-primary | `oklch(0.98 0.01 25)` | Type on red |

## Typography

- Display: Kalnia (sharp shop-sign serif)
- Body: Bricolage Grotesque (hangtag sans)

## Layout

Header as a typeset contents list. Hero is type + one cloth photograph. Stock is a numbered ledger, not a four-up card row.
